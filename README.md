# 🎮 Super Senai Bros

Jogo simples de plataforma inspirado no Super Mario, desenvolvido como projeto educacional do SENAI.

## 🕹️ Como jogar
- Movimente o personagem e pule obstáculos.
- Desvie dos inimigos e avance pelas fases.
- Chegue ao final para vencer!

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript

## 👨‍💻 Projeto
Desenvolvido para fins educacionais.
